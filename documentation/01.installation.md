# Low Options for ExpressionEngine

Low Options lists the options configured for a channel field, such as a dropdown. When a field has no configured options, it generates a list of unique values from entries that use that field, subject to the entry filters in the [Tag Reference](/low-options/documentation/tags).

The package declares **ExpressionEngine 3 or later**. Use the package intended for your installed ExpressionEngine release and follow that release’s server requirements. The changelog records EE6 and EE7 updates; these docs do not replace a compatibility check for your site.

[Low Search](https://eeharbor.com/low-search) is an optional companion add-on. The historical [EE2 branch](https://github.com/EEHarbor/low_options/tree/ee2) is separate from the current package.

## Installation

1. Download and unzip your [Low Options package](https://eeharbor.com/low-options).
2. Copy the `low_options` folder into your site’s `system/user/addons/` directory.
3. In the ExpressionEngine control panel, open **Add-On Manager** and install **Low Options**.
4. Continue to the [Tag Reference](/low-options/documentation/tags) and replace `channel_field_short_name` with the field you want to list.
